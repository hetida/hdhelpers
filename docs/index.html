hdhelpers¶

Introduction¶

hdhelpers is a package designed for and included in the standard installation of the hetida designer.

It contains functions that streamline plotting components, especially those that are used in the hetida platform, by

  • accessing metadata of series, singletsframes and multitsframes that complies with the hetida designer metadata conventions,

  • aditional helper functions like adjusting the timezone of timestamps, series, and dataframes,

  • accessing metadata that the hetida platform writes into the hetida designer’s plot_target_settings context variable (tbd),

  • providing toggleable standardized styling options and json serialization for plotly plots (tbd).

Functions¶

metadata¶

Access to the metadata of SERIES, SINGLETSFRAMEs and MULTITSFRAMEs

The metadata follows the hetida designer metadata conventions, see hdhelpers.metadata.conventions for its models. read_metadata gives the metadata of an object as model, whose methods resolve the fallbacks of the conventions. The get_* functions are thin wrappers over these methods.

class hdhelpers.metadata.Recording(recording_mode=None, data_frequency=None, data_frequency_offset=None, data_frequency_timezone=None, recording_aggregation_method=None)¶

Bases: object

How the values of a metric are recorded, as given in its metadata

The fields mean the following:

Parameters:

  • recording_mode (str | None)

  • data_frequency (str | None)

  • data_frequency_offset (str | None)

  • data_frequency_timezone (str | None)

  • recording_aggregation_method (str | None)

recording_mode¶

“periodic”: one value per interval of data_frequency, timestamped with the start of the interval. A missing value is a gap. “on_change”: a value is recorded when it changes by more than the deadband of its value dimension and holds until the next one. Missing timestamps are no gaps. “irregular”: values at arbitrary points in time. None if unknown.

Type:

str | None

data_frequency¶

Frequency as Pandas date offset alias or timedelta string, e.g. “15min”, “1D” or “1MS”. For “on_change”, the interval after which the value is recorded again at the latest, also without a change (heartbeat).

Type:

str | None

data_frequency_offset¶

Timedelta string by which the intervals of data_frequency are shifted, e.g. “5min”. None means 0.

Type:

str | None

data_frequency_timezone¶

Time zone the intervals of data_frequency are aligned to, e.g. “Europe/Berlin”. None means UTC.

Type:

str | None

recording_aggregation_method¶

Only for “periodic”: the method each value aggregates its interval with, e.g. “MEAN” or “MAX”. None if the values are samples, e.g. the value holding at the timestamp.

Type:

str | None

data_frequency_offset and data_frequency_timezone belong to data_frequency: They are None if no data_frequency applies.

hdhelpers.metadata.check_metadata_conventions(obj, data_type=None)¶

Check metadata against the metadata conventions of its data type

obj is either a SERIES, SINGLETSFRAME or MULTITSFRAME, whose attrs are then also checked for consistency with its data, or the metadata itself. For metadata, data_type is required. For data it is inferred if not provided: A DataFrame with a “metric” column is considered to be a MULTITSFRAME, otherwise a SINGLETSFRAME.

The metadata is checked in its JSON representation, as it is exchanged with adapters. Consistency is only checked if the structure is valid.

Returns the found issues, i.e. an empty list if the metadata adheres to the conventions.

Parameters:

  • obj (Series | DataFrame | Mapping[str, Any])

  • data_type (Literal['SERIES', 'SINGLETSFRAME', 'MULTITSFRAME'] | None)

Return type:

list[MetadataConventionIssue]

hdhelpers.metadata.copy_without_metadata(data)¶

Gets a copy of a Series or DataFrame without its metadata

The copy is cheap: It shares the data with data until one of them is changed (copy on write), so changing the copy does not change data. pandas operations do not copy metadata attached as model (see attach_metadata), but they copy plain metadata in attrs deeply for every object they create.

Parameters:

data (pd.Series | pd.DataFrame) – Series or DataFrame, e.g. a MTSF with metadata.

Returns:

Copy of data with empty attrs.

Return type:

pd.Series | pd.DataFrame

Code example:

>>> multitsframe.attrs = {"dataset_metadata": {"metric_key": "id"}, "metrics": []}
>>> data = copy_without_metadata(multitsframe)
>>> data.attrs
{}
>>> multitsframe.attrs
{'dataset_metadata': {'metric_key': 'id'}, 'metrics': []}
hdhelpers.metadata.get_default_aggregation_methods(multitsframe)¶

The default aggregation method of each metric of a MULTITSFRAME

The method of the metric, with “AVG” as “MEAN”. Otherwise “LAST” for boolean and string values and “MEAN” for all others, which is also the default of the returned defaultdict.

Code example:

>>> from hdhelpers.metadata.conventions import MULTITSFRAME_METADATA_EXAMPLE
>>> multitsframe.attrs = MULTITSFRAME_METADATA_EXAMPLE
>>> methods = get_default_aggregation_methods(multitsframe)
>>> methods["plant_a.temperature"], methods["plant_a.pressure"]
('MAX', 'MEAN')

multitsframe (DataFrame)

Return type:

defaultdict[str, str]

hdhelpers.helpers.modify_timezone(object_to_convert, to_timezone=None, column_names=None, convert_index=True)¶

Converts time information of pandas objects to a certain timezone

This function is applicable to index and/or columns of pd.Series or pd.DataFrame as well as for single pd.Timestamp objects. If time zone information is not defined in object to convert it is assumed that it is in UTC. Please note that column_names and convert_index are not exclusive to enable modifying both at the same time. To enable modifying the value of a series (not the index), please name the series and define the series’ name in column_names.

Parameters:

  • object_to_convert (pd.Timestamp | pd.Series | pd.DataFrame) – Timestamp, Series or DataFrame where timezone is modified

  • to_timezone (str | None) – Timezone to convert to, e.g. for German time use “Europe/Berlin”. See possible timezone strings in pandas’ tz_convert method or pytz all_timezones list. If to_timezone is not defined, the global timezone from plot_target_settings is used. .

  • column_names (str | None) – List of column_names to modify. For pd.Series the default behaviour is modifying the index and for pd.DataFrame the default behaviour is modifying the column “timestamp”. This option is not applicable in case object_to_convert is a pd.Timestamp.

  • convert_index (bool | None) – Boolean that controls whether the index of pd.Dataframe or pd.Series should be transformed. Note that for a pd.Series setting this option to true results in the same output as using column_names=None. This option is not applicable in case object_to_convert is a pd.Timestamp.

Returns:

Returns the modified timezone object.

Return type:

pd.Timestamp | pd.Series | pd.DataFrame

Raises:

TypeError – If object_to_convert is not a pd.Series, pd.Timestamp, pd.DataFrame.

Code example:

>>> from hdhelpers.helpers import modify_timezone
>>> modified_timezone = modify_timezone(pd.to_datetime("2025-01-01T01:00:00+05:00"), to_timezone="Europe/Berlin")
>>> int(modified_timezone.utcoffset().total_seconds())
3600
